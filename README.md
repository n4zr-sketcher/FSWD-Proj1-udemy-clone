# Udemy Clone - HTML & CSS

A simple Udemy-inspired course website created using HTML and CSS.  
This project was developed as a frontend practice project to learn and implement webpage structure, Flexbox layouts, course cards, navigation bars, and responsive design concepts.

## Project Overview

This project recreates the basic layout of an online learning platform similar to Udemy.

The website includes:

- Navigation bar
- Search bar
- Course categories
- Promotional banner
- Recommended courses
- Recommended topics
- Popular courses section
- Course cards with ratings and pricing
- Footer section

## Technologies Used

- HTML5
- CSS3
- Google Sans Font
- SVG Icons
- Local Images

## Features

### Navigation Bar

The navigation bar contains:

- Website logo
- Search bar
- Courses
- My Learning
- Cart icon
- Notification icon
- Profile icon

### Course Categories

The website provides different course categories such as:

- Development
- Business
- IT & Software
- Personal Development
- Design
- Marketing

### Course Cards

Each course card displays:

- Course image
- Course title
- Instructor name
- Rating
- Current price
- Original price

### Recommended Topics

The website also contains recommended topics such as:

- Website
- JavaScript
- CSS
- MongoDB
- Azure
- GitHub
- Docker
- React JS
- Wireshark

### Popular Courses

A separate section displays popular courses using reusable course card layouts.
